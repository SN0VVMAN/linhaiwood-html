林海木业网站（静态版）

文件说明：index.html 首页；product.html 与 product.js 产品详情；images 文件夹为页面图片。三者须保持相同目录结构。无需安装 Node.js 或构建。

本版本为 Sites 当前版本的独立副本，之后对 Sites 的修改不会自动同步到 GitHub。首页邮箱、社交账号和微信号沿用旧版，须核实后使用；小红书、覆膜板和细木工板实物图片待补充。规格为参考，须与工厂核对。询价功能通过访客本机邮件客户端打开草稿，不是自动提交表单。
